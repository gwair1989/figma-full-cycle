# Stage 6 — Adaptivity

## Role binding

`adaptivity-check` is bundled
[swiftui-adaptivity-check](../../../swiftui-adaptivity-check/SKILL.md), resolved by its exact
registered name including any plugin namespace. The companion owns matrix construction,
shared-rule references, evidence paths, fallbacks and completion criteria.

## Pipeline handoff

- Supply spec/UI Plan screen-state mapping and edge invariants, deployment target, resolved UI
  contracts, artifact root, capture/build bindings and current Adaptivity matrix.
- Reuse pinned design evidence when available; direct review without a mock is supported.
  Supply requested Physical device checks separately; a phone covers only its own rows.
- Request in-scope fixes under existing feature authorization. Only the orchestrator writes its
  manifest, invalidates dependent comparison/physical rows and commits.
- Import the full required matrix, report, reviewed evidence, measurements, actual mechanical
  markers or fallback reasons, and translation readiness.

## Gate

The companion's completion criteria must pass for every required row. Record its report and gate
evidence; required failed, blocked, unexecuted or stale rows keep the stage open. Missing companion
is a capability blocker. After success apply the orchestrator's ui-first pause when selected;
the companion does not decide whether to start business logic.
